# Исправление версии RPG 0.1.1 — 2026-10-07

Пользователь подтвердил работу сборки 0.1.0, затем сообщил об отказе модов
по версии Launcher. Причина: обе штатные проверки minLauncherVersion читали
VERSION=0.1.0 вместо версии базового Launcher 1.0.69.

VERSION восстановлен в 1.0.69; отдельный RPG_VERSION=0.1.1 используется
updater и его диалогом/handoff. UI показывает 1.0.69 (RPG 0.1.1).
Формат требований модов и сами проверки не изменялись.

Локально ошибка воспроизведена фактической функцией _captured_context,
выделенной из исходника без Windows-зависимых импортов, на инертном контексте.
Для прежней 0.1.0 требование 1.0.53 отклонено; после исправления требования
1.0.53/1.0.69 допускаются, 1.0.70 отклоняется. Те же границы проверены
парсером Version мод-обновлений. Updater сравнивает RPG 0.1.0 < 0.1.1.

23 существующих config/updater проверки прошли; compileall/diff-check OK.
Независимое ревью без замечаний. В Windows build добавлены к запуску уже
существующие test_mod_api_runtime_protocol.py и test_mod_updates.py;
новые тесты не создавались. Windows-сборка 0.1.1 и установка реального мода
пока ожидаются. 0.1.0 ранее собрана Actions run 37658398022: 179 passed.
